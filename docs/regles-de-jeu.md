# Règles de jeu (version 0.5)

- **Voies** : 4 voies. ← → ou clic sur une voie. La voie est **verrouillée comme réponse** quelques secondes avant le portique.
- **Portiques** : une consigne, 4 mots sur 4 panneaux, 4 voies bloquées. Bonne réponse = le bloc de ta voie s'efface ; mauvaise = collision, perte de vitesse, explication.
- **Formes** : voiture (rapide ; saute les obstacles bas et les rampes) / robot (55 % de la vitesse, enjambe les gros obstacles : blocs, liquide). Transformation 0,6 s + 3 s de recharge.
- **Progression** : la vitesse de la route augmente à chaque portique réussi ; le robot se débloque après 4 portiques.
- **Jauge de boost** : bonne réponse +25 %, +50 % si la forme était la bonne. Boost à la demande (≈ 3,5 s pour une jauge pleine).
- **Sprint final** : les 20 % de fin de tour sans question. Rangées d'obstacles : voie libre, ou boost + bonne forme pour franchir.
- **À venir** : adversaires (bots), courses thématiques, garage et déblocage de personnages, plus-value du robot (à choisir).
